Article 4: New Tablet Keyboard Case And Acode

I got a new keyboard case for my tablet it's really nice, so now I can use my tablet for long typing sessions.
In conjunction with the new case, I have also set up acode on my tablet - acode is an android ide that let's you code in a similar environment to the desktop version of visual studio code. I have acode setup so that the terminal runs as Alpine Linux, and I can as far as I'm aware run any command in the terminal that I would on my Linux laptop - except for architecture specific commands - which is really cool as I can now use acode for doing tasks and ctf challenges for AFNOM as well as working on programming projects when I don't want to bring my laptop about with me.
